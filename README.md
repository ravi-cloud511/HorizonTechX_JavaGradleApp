## 📋 Project Description
Ek simple **Student Management REST API** jo Gradle build tool aur Spring Boot framework ke saath banaya gaya hai. Yeh project DevOps practices ko demonstrate karta hai.

## ✨ Features
- Spring Boot Application
- Gradle Build System
- RESTful API (CRUD operations)
- In-memory data storage
- Proper package structure
- Ready for CI/CD Pipeline
